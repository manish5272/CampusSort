# CampusSort

CampusSort is a campus recruitment platform that connects students,
recruiters, and placement administrators through centralized job
management, skill-based matching, and application tracking.

## Main Users

- Student
- Recruiter
- Placement Administrator

## Core Features

- User authentication
- Student profiles
- Skill management
- Job posting
- Job search
- Skill-based job matching
- Candidate matching
- Job applications
- Application status tracking
- Recruitment notifications
- Admin management
- AI-assisted skill extraction

## Technology Stack

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- REST APIs
- HTML
- CSS
- JavaScript
- Git
- GitHub
